# P3 - Feature-Branch Git Workflow

## Objective
To understand and implement the Git feature-branch workflow.

## Steps Performed
1. Initialized a Git repository using `git init`.
2. Checked repository status using `git status`.
3. Added files using `git add .`.
4. Created the initial commit.
5. Created a feature branch using `git branch feature`.
6. Switched to the feature branch using `git switch feature`.
7. Modified `index.html` on the feature branch.
8. Committed the changes.
9. Switched back to the main branch.
10. Merged the feature branch into main using `git merge feature`.

## Result
Successfully created a feature branch, made changes, committed them, and merged the changes into the main branch.

The working tree was clean after the merge.
