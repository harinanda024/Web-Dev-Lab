# P4 - GitHub README and Version Tags

## Objective
To understand how to document a project using README.md and manage project versions using Git tags.

## Project Description
This project contains a simple personal portfolio webpage created using HTML.

## Technologies Used
- HTML
- Git
- GitHub

## Git Commands Practised
1. `git init` - Initialize a Git repository.
2. `git status` - Check repository status.
3. `git add .` - Stage files.
4. `git commit -m "Initial commit"` - Save the initial version.
5. `git tag v1.0` - Create a version tag.
6. `git tag` - Display available tags.

## Result
Successfully created a project README and learned how to use Git tags to identify a specific version of a project.
